# ADR 0002: Линейная AU-карта и единая state-vector модель

## Статус

Принято, 2026-10-10.

## Решение

Обе карты используют один каталог и один формат `x,y,z,vx,vy,vz`. Дальний космос остаётся линейной шкалой 0–250 а.е.; zoom и pan изменяют transform Canvas, но не искажают расстояния логарифмической проекцией.

## Причины

Пользователь должен видеть честное сравнение расстояний. Общая модель исключает расхождение карточки и карты и оставляет путь к 3D без переписывания астродинамического слоя.
