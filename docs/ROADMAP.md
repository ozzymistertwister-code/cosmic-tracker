# Roadmap

## v0.1.2 — текущий MVP

- Две 2D-карты на реальных Horizons vectors.
- SQLite cache, статусы источников, Hermite interpolation.
- Responsive dark UI, production prefixes и документация.

## Следующая итерация

- Независимый cross-check через NAIF/ESA SPICE.
- Отдельная относительная скорость к Земле и переключение km/s ↔ km/h.
- Второй каталог межпланетных аппаратов: Solar Orbiter, BepiColombo, Lucy, Psyche, Hera.
- События миссий с официальными источниками и датой проверки.

## Более поздние этапы

- 3D renderer на общей state-vector модели.
- CelesTrak/SGP4 для околоземных объектов.
- Расширенная мобильная bottom-sheet карточка.
- Публичный docs site под `/cosmic-tracker/docs/` после отдельного review.
